Как проверить текст в Telegram

  1. Подготовьте Telegram. Полностью выйдите из приложения и запустите его командой ниже.QT_LINUX_ACCESSIBILITY_ALWAYS_ON=1 /usr/bin/telegram-desktop
  2. Откройте тестовый чат. Введите DLP_TEST в поле сообщения и оставьте окно видимым.
  3. Нажмите «Проверять текст». После готовности модуля изменяйте черновик. Предупреждения появятся на рабочем столе, результаты — в журнале. Отправлять сообщение не нужно.
Что важно знать

Закрытие панели не останавливает агент. Файловая служба установленного DEB может запускаться автоматически. Карточки файлов и текста здесь относятся к лабораторным пользовательским модулям. База Signal проверяется разово по кнопке; для Telegram и JSON-экспорта доступны команды ниже.

Команды для разовых проверок

Для собственного профиля без код-пароля: сначала полностью закройте Telegram с сохранённым тестовым черновиком DLP_STORAGE_TEST.

./scripts/dlp agent local --profile-closed --no-passcode

Проверка искусственного JSON-примера:

./scripts/dlp agent export --file examples/telegram-export-synthetic.json

BLOCK — решение анализа. DENY — отказ открытия файла. Эти события не подтверждают отправку сообщения. Содержимое переписки и документов здесь не отображается.

Статус процесса не доказывает готовность контроля. Учитываются модули, запущенные через agent; ручные процессы не включены.

Правила принятия решений

Настройки файла config/policy.yaml. Работающие модули читают политику при запуске: после сохранения их нужно перезапустить отдельно. Новые категории дают только WARN.

ML — обученная экспериментальная модель. Возможны ложные тревоги. Работает отдельно от правил; требует перезапуска модуля после включения. Модель анализирует до 16 КиБ текста, без OCR.

Пороги: 0 ≤ WARN < BLOCK. ALLOW при ошибке разрешает обработку непроверенного содержимого. Отключение новых категорий уменьшает покрытие контроля.
