# DLP Lab для Linux

Система контроля утечек для **Telegram Desktop и Signal Desktop**, разработанная
в рамках ВКР. Агент анализирует данные на рабочей машине; администратор видит
события и управляет компонентами через центральную веб-панель.

| Компонент | Развёртывание | Назначение |
| --- | --- | --- |
| Сервер | Docker Compose + HTTPS | Устройства, события, политики, диагностика и перезапуск компонентов |
| Агент | DEB + один профиль подключения | Файловый контроль, анализ текста, уведомления и доставка событий |

## Быстрый старт

**Сервер:** один раз по [инструкции](docs/INSTALL.md#1-сервер); на каждую рабочую
машину администратор готовит отдельный `connection.json`.

**Клиент Debian 13/12 amd64** — в каталоге с пакетом и профилем:

```bash
sudo apt install ./dlp-lab_*_amd64.deb
sudo dlp-setup connection.json
```

Telegram устанавливается заранее. Для Debian 12 нужен пакет с суффиксом
`~deb12u1` (SQLCipher 4 уже внутри). Готовые сборки лежат в `build/`
сборочной машины, в Git не попадают; сборка — [DEVELOPMENT](docs/DEVELOPMENT.md#сборка-пакета).

## Возможности

- Контроль открытия файлов мессенджерами через fanotify; анализ текста, PDF и DOCX.
- Настраиваемая блокировка файлов по типу/сигнатуре (например, изображений) — отдельно на каждое устройство.
- Правила и ML-классификация чувствительных данных.
- Наблюдение за доступным полем ввода через AT-SPI, предупреждения и журнал.
- Отдельный анализ локальных черновиков Telegram, JSON-экспорта и сохранённых текстов Signal.
- Сбор событий по HTTPS, итоговая «Операция с файлом», состояние устройств.
- Диагностика, перезапуск компонентов и применение YAML-политик из панели.
- Консольное меню администратора `dlp-lab`: статус, добавление устройства, журналы, резервная копия.

Файловый запрет подтверждается `enforcement: DENY`; решение `BLOCK` само по
себе не доказывает блокировку. Для текста — предупреждения и журнал без
запрета отправки. Полная локальная история Telegram не читается; доступность
поля зависит от AT-SPI-клиента. Обновление пакетов из панели не реализовано.

## Репозиторий

`src/dlp/` — анализ, адаптеры, сервер; `native/` — файловый перехват;
`packaging/` и `debian/` — пакет и службы; `docker/` — серверный образ;
`tests/` — тесты; `data/ml/` — данные ML. Токены, ключи, подключения,
профили мессенджеров и рабочие журналы не публикуются. Лицензия — [MIT](LICENSE).
