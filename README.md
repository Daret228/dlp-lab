# DLP Lab для Linux

Агент контроля утечек для Telegram Desktop и Signal Desktop, разработанный
в рамках ВКР. Анализ выполняется на рабочей машине, события доступны администратору
в центральной веб-панели.

## Как устанавливать

| Куда | Что устанавливается | Как |
| --- | --- | --- |
| Сервер администратора | Центральная панель и хранилище событий | Docker Compose + HTTPS-сертификат |
| Рабочая машина | Агент и службы systemd | Установочный комплект: DEB + `install-dlp.py` |

**Одного DEB и запуска Docker недостаточно для связи между ними.** Для каждой
машины сервер выдаёт индивидуальный файл регистрации. Вместе с публичным CA
его передают установщику агента. Установщик настраивает файловую защиту,
отправщик событий и их автозапуск. Текстовые поля и локальные данные запускаются
отдельно в пользовательском сеансе.

**Начните с [установки и эксплуатации](docs/OPERATIONS.md).**
Сервер: [Docker — новый сервер и текущий стенд](docs/DOCKER.md).

## Что работает

- Контроль открытия файлов Telegram и Signal через fanotify; анализ текста, PDF и DOCX.
- Правила и ML-модель для чувствительных данных; ML-предупреждения.
- Наблюдение за тестовым полем ввода через AT-SPI, уведомления и журнал.
- Проверка локального черновика Telegram, JSON-экспорта и сохранённых текстов Signal.
- Сбор событий нескольких устройств по HTTPS, группировка повторных открытий,
  запрос диагностики через панель.

Файловый BLOCK означает запрет открытия. Текстовый BLOCK — результат анализа,
не запрет отправки. Полная локальная история Telegram не читается. Постоянный
мониторинг поля без тестового маркера и обновление агентов из панели не реализованы.

## Текущее состояние

Подготовлен агент **0.2.18**: локальная веб-панель удалена, остаётся центральная
административная панель. Для удаления команды из установленного агента нужен
пакет 0.2.18 для соответствующей ОС; сервер пересобирать не требуется.


На 06.11.2026: основной агент Debian 13 — **0.2.17**, второй Debian 12 —
**0.2.17~deb12u1**, сервер в Docker — **0.2.17**. Последняя проверка:
287 тестов прошли, 3 специальных пропущены; проверено сохранение настроек
при обновлении Debian 12. Новое реальное событие после обновления второго
агента ещё требует проверки в панели.
