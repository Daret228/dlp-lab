# DLP Lab для Linux

Система контроля утечек для **Telegram Desktop и Signal Desktop**, разработанная
в рамках ВКР. Агент анализирует данные на рабочей машине; администратор видит
события и управляет компонентами через центральную веб-панель.

| Компонент | Развёртывание | Назначение |
| --- | --- | --- |
| Сервер | Docker Compose + HTTPS | Устройства, события, диагностика и перезапуск компонентов |
| Агент | DEB + один профиль подключения | Файловый контроль, анализ текста, уведомления и доставка событий |

## Быстрый старт

**Сервер:** один раз выполните [инструкцию Docker](docs/DOCKER.md#новый-сервер-с-нуля).
На каждую рабочую машину администратор готовит отдельный `connection.json`.

**Клиент Debian 13 amd64:** в каталоге с пакетом и профилем выполните:

```bash
sudo apt install ./dlp-lab_0.2.24_amd64.deb
sudo dlp-setup connection.json
```

Команда настраивает и запускает службы. Telegram должен быть установлен заранее.
Для Debian 12 нужен соответствующий пакет; SQLCipher 4 уже включён в него.
[Подготовка профиля, Debian 12 и автоматический postinst](docs/OPERATIONS.md).

**Где взять DEB:** готовые сборки находятся в `build/` на сборочной машине,
в Git они не хранятся. Администратор передаёт пакет клиенту или собирает его
по [инструкции разработчика](docs/DEVELOPMENT.md#сборка-пакета).

## Возможности

- Контроль открытия файлов мессенджерами через fanotify; анализ текста, PDF и DOCX.
- Правила и ML-классификация чувствительных данных.
- Наблюдение за доступным полем ввода через AT-SPI, предупреждения и журнал.
- Отдельный анализ локальных черновиков Telegram, JSON-экспорта и сохранённых текстов Signal.
- Сбор событий по HTTPS, группировка повторных открытий, состояние устройств.
- Запрос диагностики и перезапуск файлового или текстового компонента из панели.

Файловый запрет подтверждается `enforcement: DENY`; решение анализатора `BLOCK`
само по себе не доказывает блокировку. Для текста работают предупреждения и журнал,
без запрета отправки. Полная локальная история Telegram не читается. Доступность
поля зависит от AT-SPI клиента. Обновление пакетов из панели пока не реализовано.
