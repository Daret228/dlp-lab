# Зафиксированные результаты

Отчёты и манифесты экспериментов v3/v4 от 2026-10-14. Только метрики, ID
синтетических примеров и SHA256, без пользовательских данных. Модели в build/ml
не входят в Git, воспроизводятся скриптами. В v4 используются те же веса/пороги
ML, что в v3; изменено связывание признаков правил со значениями.

V3 прошёл 120 новых примеров. V4 прошёл критерий на дополнительных 60 с двумя
пропусками. В обоих случаях ML отдельно существенно хуже, а rules и hybrid
на holdout совпали. Отдельная польза ML на holdout не доказана.

Полный протокол: docs/research/ml_hybrid_2026-10-14.md.
