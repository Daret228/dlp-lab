# Синтетический набор v2 — первый эксперимент ML

Дата: 2026-10-14. Продолжение synthetic-v1; исходная версия сохранена.
Пользователь подтвердил: логин без пароля не секрет; конкретные пароли, токены,
коды входа — чувствительные данные; паспортные серия/номер — чувствительные;
обычное упоминание паспорта — нет; полные банковские реквизиты, персональные
зарплаты и долги выявляются, обычные цены покупок не выявляются.
Это согласование границ, не построчная проверка набора пользователем.

Добавлены 48 отдельных сценариев и 12 смешанных примеров. Всего 156:
104 train, 26 dev, 26 test. В каждой выборке есть обычные тексты и все три
категории; смешанная запись может содержать несколько меток. Новые случайные
секреты всё равно полностью вымышлены и не действуют в каких-либо сервисах.
Реальные документы и переписки не использовались. Числа не проверены по реестрам.

review.json сохранён как исторический список пограничных вопросов: в этой версии
он не используется ни для обучения, ни для оценки. Ответ на вопрос об одном
логине и кодах входа следует из подтверждённых выше границ; остальные спорные
детали (учебные примеры секретов, неполные реквизиты и др.) отдельно не согласованы.
Предварительные построчные метки не означают подтверждение каждого случая.

Формат, правила группировки, запрет подачи служебных полей модели и ограничения
синтетики описаны в ../synthetic-v1/README.md. В v2 добавлены смешанные метки и
варианты секретов без Example, но это не устраняет артефакты синтетических данных.
Словарь модели обучается только на train; подбор порогов только на dev. Модель
сохранена до первой оценки test. Результаты test теперь известны: дальнейшая
разработка с их учётом требует новой независимой итоговой проверки.

Проверка:

```sh
python3 scripts/validate-ml-corpus.py --data data/ml/synthetic-v2
```

Результат первого обучения: docs/research/ml_baseline_2026-10-14.md.
