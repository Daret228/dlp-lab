# Контрастные примеры v3 (2026-10-19)

619 train / 82 dev / 44 test. Все сведения вымышлены.

- Train: 468 прежних обучающих примеров, 60 раскрытых test-v2 и 91 новый
  контрастный пример. Варианты шаблонов остаются внутри train.
- Dev: 66 прежних и 16 новых примеров, применяется для выбора параметров.
- Test: 44 новых предложения, записаны до обучения v5; 20 обычных и по
  8 примеров каждой чувствительной категории. После оценки считается раскрытым.
  Автор и темы совпадают с обучающей выборкой, поэтому это диагностический
  набор, а не независимая внешняя проверка.

Рабочая разметка: финансовые сведения о конкретном человеке/закрытой отчётности
положительны, публичные цены и объявления о вакансии отрицательны.
Паспорт человека положителен; технический паспорт/заказ/артикул отрицателен.
Конкретный пароль или код входа положителен; инструкция или упоминание без
значения отрицательны. Эти границы требуют подтверждения предметным экспертом.
Синтетические коды и номера не являются действующими реквизитами.

Точные дубли и пересечения групп проверяет scripts/train-ml-linear.py.
Шаблонная и смысловая близость не исключается этой проверкой.
Для следующего объективного опыта нужна новая разметка другим человеком;
нельзя подбирать параметры по test этого каталога и считать его закрытым.
