## Оформление и повторная сборка

Основание — предоставленное пособие Плотниковой и Климовой, 2023,
ISBN978-5-7996-3779-8. A4, поля30/15/20/20мм, Times New Roman14,
интервал1,5, абзац1,25см. Таблицы/подписи12пт. Нумерация снизу по центру,
титул учитывается без номера. Пять приложений, 24 источника, девять рисунков (пять схем и четыре места под скриншоты),
18 нумерованных таблиц (20 физических таблиц OOXML с двумя продолжениями). Реферат пересчитывает рисунки и таблицы автоматически.

На хосте нет Times New Roman: контрольный LibreOffice использует Liberation
Serif. В DOCX задан Times New Roman; в Word с этим шрифтом необходимо обновить
содержание и проверить переносы. Дополнительных требований кафедры нет.

Тексты: `chapters/`, библиография: `references.json`. `build_thesis.py` заменяет
итоговый DOCX: ручные правки Word предварительно сохранить либо перенести в
исходники. `update_page_map.py` строит кэш содержания из pdftotext -layout.

Используется комплектный Python:
`/home/roman/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`.
Renderer:
`/home/roman/.codex/plugins/cache/openai-primary-runtime/documents/26.1026.10807/skills/documents/render_docx.py`.
В PATH перед системными командами помещается комплектный каталог
`/home/roman/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/override`.
Порядок: builder → renderer с --emit_pdf → pdftotext -layout → update_page_map.py
→ повтор builder/renderer → сверка страниц и визуальная проверка.

Измерения6октября не запускались повторно и сохранены историческими.
Новые метрики ML взяты из docs/research/ml_quality_2026-10-19.md и протоколов,
