# Материалы ВКР

Версия от 2026-10-12, состояние реализации на 2026-10-11. Итоговый файл: `output/docx/VKR_DLP_Linux.docx`.
В проверенном рендере 65 страниц, 4 главы, 5 рисунков, 16 нумерованных таблиц,
24 источника и 5 приложений. Это содержательная версия для согласования с руководителем.
ФИО, организация, специальность, группа, руководитель, подписи, город, год и сроки
оставлены полями по прямому указанию пользователя. Подписанное задание не имитируется.

## Оформление

Основание — предоставленное пособие Плотниковой и Климовой, 2023,
ISBN 978-5-7996-3779-8, файл в корне проекта.

| Требование | Применение |
|---|---|
| Рекомендуемый объём специалиста 50–90 страниц | 65 страниц в проверенной сборке |
| A4, поля слева 30, справа 15, сверху/снизу 20 мм | Заданы в секции DOCX |
| Основной текст Times New Roman 14, интервал 1,5 | Стиль Normal, абзац 1,25 см |
| Таблицы и подписи 12 пунктов | Отдельные стили; код моноширинный 12 |
| Номер страницы внизу по центру | Поле PAGE, титул учитывается без номера |
| Основные разделы с новой страницы | Heading 1, полужирный, по центру |
| Содержание, ссылки и приложения | Поле TOC с проверенным кэшем; ссылки [1]–[24]; А–Д |
| Подписи и продолжения | Таблицы сверху, рисунки снизу; продолжения А.1 и Д.1 |

На хосте отсутствует Times New Roman: при контрольном рендере использована
подстановка Liberation Serif. В DOCX указан именно Times New Roman. Поэтому
после открытия на компьютере с этим шрифтом следует обновить содержание и
сверить переносы и число страниц реферата. Дополнительные требования кафедры
и утверждённый бланк задания не предоставлены.

## Источники и повторная сборка

Тексты находятся в `chapters/`, библиография — в `references.json`.
`build_thesis.py` собирает документ и диаграммы. Он перезаписывает итоговый DOCX:
ручные правки Word предварительно сохранять отдельной копией или переносить в исходники.
`update_page_map.py` пересчитывает кэш содержания по результату pdftotext.

Использован Python из
`/home/roman/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`.
Рендер выполнялся скриптом
`/home/roman/.cache/codex-runtimes/codex-primary-runtime/plugins/openai-primary-runtime/plugins/documents/skills/documents/render_docx.py`
с `--emit_pdf`, исключительно через комплектный LibreOffice
`/home/roman/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/override/soffice`.

Порядок: запустить builder → render_docx → pdftotext -layout →
update_page_map.py с путём к тексту → повторить builder и renderer → сверить
стабильность страниц и просмотреть изображения. В Word содержание можно обновить
через контекстное меню поля. После правок текстов нужно повторить проверку.

## Эксперимент и проверка

`measure_synthetic.py` — сохранённый скрипт фактически проведённого опыта.
Запуск из корня проекта: `PYTHONPATH=src:.deps python3 docs/thesis/measure_synthetic.py`.
Он заменяет `docs/research/thesis_synthetic_experiment_2026-10-06.json`;
для новой серии сначала сохранить прежний протокол отдельно.
16 функциональных случаев совпали с ожиданием; 8 диагностических проб показали
границы текущих правил. Эти результаты не являются независимой оценкой точности DLP.
