# Контекст проекта DLP Lab

Последнее обновление: **2026-11-17**. Итоговая версия: **0.2.38**.

## Состояние проекта

Разработка учебного прототипа завершена на версии 0.2.38. Выпуск
[v0.2.38](https://github.com/Daret228/dlp-lab/releases/tag/v0.2.38)
опубликован: DEB для Debian 13/12 amd64 и SHA256SUMS. Бинарные сборки,
ключи, профили, рабочие журналы и итоговый DOCX не хранятся в Git.

Все три направления реализованы: анализ доступных локальных данных
Telegram/Signal, контроль файлов через fanotify, наблюдение за доступными
текстовыми полями через AT-SPI. Есть правила и ML, центральная панель
Docker/HTTPS, политики на устройство, диагностика, перезапуск и обновление
агентов из панели. Подробности установки и эксплуатации — в INSTALL,
ADMIN, SERVER; модель доверия — в threat_model.md.

## Работа компонентов

Файловый запрет фиксируется как enforcement: DENY, решение анализатора —
как BLOCK. Журнал файлов отражает операции открытия. Текстовый контроль
показывает предупреждения и записывает события. Локальный анализ Telegram
работает с черновиками и JSON-экспортом; Signal — с сохранёнными текстами.

Обновление пакета выполняется от root по назначению администратора сервера.
Агент проверяет TLS, token, SHA-256, метаданные и версию пакета.
Порядок выбора пакета и восстановления описан в ADMIN.
