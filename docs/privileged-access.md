# Привилегии файлового контроля

В текущем развёртывании привилегированный компонент запускается системной
службой `dlp-lab-files.service`, устанавливаемой DEB-пакетом. Анализ содержимого
выполняется непривилегированным процессом. Настройка — через установщик агента
или `sudo dlp-lab-configure --wizard`.

[Установка](OPERATIONS.md) · [Ручной запуск и тестирование](DEVELOPMENT.md)

Не запускайте параллельно второй файловый монитор. Для разработки
привилегированных тестов нужен отдельный согласованный тестовый запуск;
обычный `make test` не выполняет все привилегированные проверки.
