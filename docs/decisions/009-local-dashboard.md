# 009. Локальная панель событий

Дата: 2026-10-15. Статус: реализована первая версия только для просмотра.

Для первоначальной панели используется существующий journald и стандартная
библиотека Python. Это позволяет проверить нужные представления без установки
отдельного поискового кластера. Предложение OpenSearch/Dashboards для центрального
сбора остаётся возможным будущим этапом, не считается реализованным.

Панель читает только фиксированные user-units агента. Отдельной базы нет, предел
выборки — 1000 записей за 1/7/30 дней. Сервер возвращает только разрешённые поля
событий. Ошибка чтения или получения статуса отображается отдельно: пустая
выборка не подменяет недоступный источник. Счётчики — события в загруженной
выборке, не число утечек. Решение анализа отделено от применённого действия.

Сервер привязан к 127.0.0.1. API защищён случайным ключом процесса и проверкой
Host/Origin. Нет маршрутов изменения состояния. Статические файлы доступны без
ключа, но журнал — только с Authorization. Ключ передаётся в fragment, удаляется
из адреса после загрузки, сохраняется в sessionStorage вкладки. Нет CORS, внешних
ресурсов или интерпретации событий как HTML. CSP запрещает inline scripts,
встраивание во frame и формы. Прототип не защищает от скомпрометированного
браузера или процессов того же пользователя и не предназначен для LAN/Internet.

Статус active означает работающий процесс, не доказанную готовность контроля.
Содержимое сообщений, документов, путей и произвольные metadata не выдаются.
Роль администратора, редактирование политики, управление модулями, экспорт
отчётов и централизованное хранение — отдельные будущие задачи.

Проверено: 148 тестов (146 прошли, 2 opt-in пропущены), в том числе 8 новых
проверок API/проекции/источника. В браузере на реальном журнале видны 65 событий
за 7 дней, фильтр финансовых данных оставляет одно. Проверены пустая выборка,
перезагрузка страницы с сохранением доступа, отображение остановленных модулей.
Визуально проверена текущая узкая панель браузера; отдельная проверка всех
настольных разрешений не проводилась. Браузерная вкладка оставлена пользователю.
