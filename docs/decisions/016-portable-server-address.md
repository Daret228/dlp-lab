# ADR-016: постоянное имя сервера при переносе VM

Дата: 2026-11-15. Решение принято к реализации по прямому запросу пользователя;
развёртывание и межмашинный опыт ещё требуют проверки.

## Причина

После переноса VM адрес 192.168.17.131 сменился на 192.168.200.128.
У HTTPS-контейнера в host network остался DLP_TLS_HOST=192.168.17.131;
процесс завершался с OSError и перезапускался. Локальный HTTP listener был
healthy. Старые профили и сертификат также были связаны с прежним IP.

## Решение

- Разделить bind и адрес сервиса: HTTPS слушает 0.0.0.0, профили содержат
  стабильное DNS-имя. Loopback HTTP остаётся неизменным.
- Для текущего стенда использовать уже объявляемое Avahi имя debian.local.
  Это локальный вариант; для нескольких подсетей требуется управляемый DNS/VPN.
  Не писать IP в /etc/hosts и не отключать hostname/CA verification.
- Один раз выпустить DNS SAN сертификат существующим CA. Сохраняются CA,
  токены, идентификаторы устройств и база. Старый IP SAN не поддерживается:
  остальные агенты явно переводятся на имя с проверкой HTTPS до изменения.
- Миграция выполняется root-скриптом с dry-run по умолчанию, резервной копией,
  атомарной заменой файлов и откатом при обычном сбое. Новых sudoers/SUID нет.
  Обновлятор пакетов не затрагивается.
- Установка новых Compose-стендов документирует DNS SAN и wildcard HTTPS bind.
  Исторический скрипт миграции также больше не привязывает HTTPS к LAN IP.
- При OSError центральный CLI сообщает errno и стандартное описание ОС,
  не выводя текст исключения с возможными путями/содержимым.

## Ограничения

Wildcard HTTPS доступен через все IPv4-интерфейсы; сетевой доступ ограничивается
firewall. mDNS требует общего сегмента, resolver на клиентах и multicast;
изоляция сети, VPN, конфликт имён и смена hostname не решаются самим DLP.
В обычном DNS запись должна обновляться при смене IP. Сертификаты по-прежнему
имеют срок действия; постоянное имя не заменяет обслуживание PKI.
Автоматическое обновление профилей недоступных агентов не заявляется.
SIGKILL/потеря питания в середине миграции требуют восстановления из копии.
Работа local listener и active служб не доказывают доставку событий.
