# SQLCipher внутри пакета Debian 12 — 08.11.2026

Цель: передавать клиенту один DEB DLP вместо DLP + backport SQLCipher.
Выпуск: 0.2.23~deb12u1 amd64. Системная SQLCipher не заменяется.

## Состав и происхождение

Включён runtime из ранее собранного на Debian12 libsqlcipher1 4.6.1-2~dlplab12.1.
Происхождение исходников и сборка: [перенос Debian12](debian12_port_2026-10-30.md).
SHA-256 входного DEB:
`1be243f9b4e36186990e93e951aec966ff67ed436ee0a05032349826a255670b`.

Сборщик проверяет хеш, Package/Version/Architecture, извлекает только библиотеку
и copyright. Нет общего распаковывания архива и изменений /usr/lib системы.
Библиотека установлена как root-owned0644 в каталоге0755
`/usr/lib/dlp-lab/lib/libsqlcipher.so.1`. Лицензия находится в
`/usr/share/doc/dlp-lab/copyright.sqlcipher`. ELF-зависимости рассчитываются
на Debian12: libc6>=2.34, libssl3>=3.0.0; зависимости libsqlcipher1 больше нет.
Размер DLP DEB около893KiB вместо дополнительного файлаSQLCipher.
Обновления безопасности этой встроенной копии требуют нового выпуска DLP.

## Проверки

- Debian12 и Debian13:300 тестов,297pass/3skip на каждой ОС.
- Выбор приватной библиотеки по умолчанию, сохранение явного пути,
  отказ сборке при отсутствующем/неизвестном артефакте.
- Изолированный lifecycle без системной SQLCipher: удалена только регистрация
  пакета в одноразовом chroot; до загрузки приватной копии обычный CDLL по SONAME
  завершается ошибкой. Затем load_library выбирает приватный путь, создаётся
  синтетическая зашифрованная база и читается через ReadOnlySignalDatabase.
- Отдельно обновление0.2.22→0.2.23 при установленной системной SQLCipher:
  сохранение политики/процессов/настройки, чтение базы, remove/purge — PASS.
- Проверены Depends, состав/права DEB, включённый copyright и синтаксис команд.

В первом варианте проверки отсутствие системной библиотеки ошибочно проверялось
после загрузки приватной: загрузчик уже знал тот же SONAME. Проверку перенесли
до загрузки, после чего изолированный опыт прошёл. Это было свойство проверки,
не присутствие системного файла в тестовом корне.

Изоляция не является новой чистой VM: реальный GUI/systemd/сетевое подключение
на чистой машине не проверялись. Рабочие агенты и профили пользователей не менялись.
Другие зависимости получает apt из штатных репозиториев; полностью offline
установка одним файлом не заявляется. Debian13 сохраняет системную SQLCipher4.
