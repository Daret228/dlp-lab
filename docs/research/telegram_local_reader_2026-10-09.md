## Реализация

- `src/dlp/telegram_local.py`: ограниченный reader контейнера TDF$, проверка
  MD5 в соответствии с форматом Telegram, современная derivation локального
  ключа, AES-IGE и проверка внутреннего SHA-1, карта ссылок на черновики,
  QString UTF-16BE и структуры черновика.
- `scripts/analyze-telegram-local-draft.py`: закрытый профиль → сбор ограниченного
  зашифрованного набора → временная копия → повторная проверка → один черновик
  с тестовым маркером → TextContent → общий анализатор → JSONL без исходного текста.
- Читаются только key_datas, maps и файлы черновиков, на которые указывает карта.
  maps расшифровывается в памяти для определения ссылок. Остальные поля карты
  пропускаются по схеме, сведения self/webview не декодируются и не выводятся.
  configs и файлы сетевой авторизации не открываются. Информация об аккаунтах
  из третьего поля key_datas не расшифровывается.
- Для поиска маркера читаются все доступные черновики выбранного единственного
  аккаунта в пределах лимита. В реальном опыте был ровно один. Поэтому запуск
  предназначен для собственного тестового профиля; маркер не является механизмом
  избирательного доступа до расшифровки.
- Копия содержит зашифрованные файлы, каталог 0700, файлы 0600; после завершения
  удаляется. Ключи и текст обрабатываются только в памяти. Core dumps отключены.
  Python не гарантирует обнуление всех копий секрета в памяти; swap и root-доступ
  остаются за пределами защиты прототипа. SIGKILL может оставить временную копию.

## Запуск

На этом стенде зависимость PyCryptodome 3.23.0 установлена в .deps из PyPI
с проверкой SHA-256 wheel. В обычном окружении с pip:

```bash
python3 -m pip install -e '.[telegram-local]'
```

Для повторения оставить только искусственный тестовый черновик
`DLP_STORAGE_TEST коммерческая тайна`, не отправлять, полностью выйти из Telegram.
Из корня проекта, без sudo:

```bash
PYTHONPATH=src:.deps python3 scripts/analyze-telegram-local-draft.py \
  --root /home/roman/.local/share/TelegramDesktop/tdata \
  --profile-closed --no-passcode --expect-demo
```

Ожидаются local_draft_analysis, expected_demo_match=true, complete=true,
decision=BLOCK. Код 0 — завершённый анализ, включая BLOCK; 2 — ошибка или
неполный анализ; 130 — прерывание. Ошибка источника не превращается в ALLOW.
`--profile-closed` — подтверждение оператора; сам скрипт не останавливает клиент
и не гарантирует отсутствие других процессов. `--no-passcode` не подбирает
пароль: при защищённом другим паролем ключе будет ошибка. Для известного локального
пароля опустить флаг: ввод только в интерактивном терминале, не в аргументах.

## Проверки и границы

9 новых тестов: OpenSSL AES-IGE как независимая проверка блочного преобразования;
пароль/повреждения; лимиты контейнера и полей; неподдерживаемая схема;
неизменность исходных файлов; отсутствие чтения configs; симлинки/FIFO;
дубликат маркера и несовпадение ссылки; отсутствие текста и ID в CLI; код ошибки.
Общий `make test`: 74 теста, 72 прошли, 2 привилегированных opt-in пропущены.
Реальный опыт подтверждает совместимость локальной записи с reader, но не
аттестует версию установленного бинарника. Writer контейнера — 7002008,
реальная схема черновика — FFFFFFFFFFFFFF06.

Текущие ограничения: только writer 7002008, один каталог аккаунта, современные
файлы с суффиксом s, максимум 32 файла черновиков, файл до 4 MiB, поле текста
до 1 MiB UTF-16, 30-секундный сигнал таймаута (не жёсткая гарантия при kernel IO).
Теги FF01/FF03/FF05 также разобраны в коде, но реально проверен только FF06.
Неизвестные секции карты/версии отклоняются. Сравнение до/после чтения и копирования
не делает snapshot атомарным. Требуется закрытый клиент.

Текст передаётся анализатору без разметки; метаданные включают лишь наличие
форматирования, ответа и предпросмотра. Не анализируются скрытые URL и вложения.
Нет чтения полной истории, timestamps сообщений, sender/recipient, постоянного
мониторинга, systemd-интеграции нового reader или автоматического запрета отправки.

Следующий шаг — реальные ALLOW/WARN и форматированный черновик, затем выбранные
метаданные вложений с отдельным исследованием схемы. Полную историю не обещать:
наличие локально сохранённых черновиков её не доказывает. DOCX пока не обновлён.
