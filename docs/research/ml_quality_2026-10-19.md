# Улучшение качества ML — 2026-10-19

## Изменения

Сформирован набор linear-v3: 619 train / 82 dev / 44 test (состав и правила
разметки — data/ml/linear-v3/README.md). Добавлены контрастные примеры публичных
цен и личных финансов, паспортов оборудования и людей, инструкций и конкретных
кодов входа. Старый раскрытый test-v2 перенесён в train, его нельзя использовать
как независимую оценку обновлённой модели.

В features v3 увеличен вклад символьных n-грамм для словоформ: веса
слово/биграмма/символьный признак = 2/2/1 вместо 3/5/0.35.
Совместимость с прежними версиями признаков сохранена.
Добавлена стратегия --precision-with-recall: подбор порога по F0.5 на dev,
при полноте не ниже 0.85 (если достижима; иначе максимум полноты).
Сетка порогов 0.01…0.99. Это ограничение относится к dev, не гарантирует
полноту на новых данных. Оно предотвращает выбор порога без срабатываний
только ради отсутствия ложных тревог. Веса по test не обучаются.

## Результаты

Все строки таблицы оценены на одних и тех же 44 текстах: 20 обычных,
24 чувствительных (по 8 каждого класса). Единица пропуска здесь — пример,
а не фрагмент текста.

| Вариант | Ложные тревоги / 20 | Пропуски / 24 | Полностью верно / 44 | Macro F1 |
|---|---:|---:|---:|---:|
| Предыдущая поставляемая модель v4 | 10 | 3 | 31 | 0.7643 |
| v5: только дополнение данных | 6 | 4 | 34 | 0.8020 |
| v6: изменение весов признаков | 7 | 0 | 37 | 0.8733 |
| v7: F0.5 с ограничением полноты на dev | 3 | 2 | 39 | 0.8957 |
| Правила v4 без ML | 2 | 4 | 38 | 0.8638 |

Выбран v7 для уменьшения ложных предупреждений; относительно v6 это компромисс
в пользу точности. На dev ложные тревоги снижены с 7 до 4 из 30 обычных;
macro F1 изменился с 0.9395 до 0.9364. На test v7: financial TP8/FP2/FN0,
passport TP8/FP1/FN0, credentials TP6/FP0/FN2.
Пороги: financial 0.55, passport 0.64, credentials 0.70.

Новый test был записан до обучения v5; результаты v5 просмотрены перед дальнейшей
доработкой. Поэтому test для v6/v7 **раскрыт**. Тексты синтетические, автор и темы
совпадают с обучающими. Это диагностическое улучшение, не независимое доказательство
обобщения. Сравнивать прежние 6/24 и нынешние 3/20 как одну выборку нельзя.
Оставшиеся ошибки и все метрики сохранены по ID в experiment-reports/linear-v7.
