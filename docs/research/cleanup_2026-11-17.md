активной сборки, отсутствие отслеживаемых Git файлов среди целей и отсутствие
каталогов tdata внутри удаляемых деревьев. Telegram запускается из

Всего 106 целей, 19 276 файлов, около 1,85 ГиБ по выделенным блокам удалённых
файлов. Это сумма размеров, а не гарантия точного изменения df при работающих
приложениях. Каталог проекта после очистки — 436 МиБ. Реестр удалений сохранён
локально в build/cleanup-2026-11-17.json; содержимое профилей/ключей не включалось.

Сохранены:
- исходники, все отслеживаемые файлы, история Git и исследовательские протоколы;
- CA и его ключ; контрольные суммы не изменились;
- итоговый DOCX, page_map.json, все небольшие резервные копии исходников ВКР,
  последний render2 и отдельно документированный review-verified-2026-11-03;
- пакеты Debian13 0.2.35+livecheck1 и 0.2.35, Debian12 0.2.35~deb12u1 и
  0.2.34~deb12u1; входной пакет SQLCipher для повторных сборок;
- зависимости .deps, рабочие runtime, база сервера, журналы и резервные копии
  рабочих настроек, профили подключений и подготовленный PNG-опыт.

Установщик ChatGPT в Downloads сохранён. Перед удалением временной копии
проверено побайтное соответствие по SHA256. Ключ CA, его сертификат, DOCX,
карта страниц и SQLCipher DEB проверены по SHA256 до/после удаления.

Причина накопления build/deb-source исправлена в scripts/build-deb.sh:
после успешного dpkg-buildpackage EXIT trap удаляет только текущий snapshot;
при ошибке snapshot и код возврата сохраняются. DLP_KEEP_BUILD=1 явно сохраняет
успешную копию. DEB/buildinfo/changes находятся вне snapshot и не удаляются.
Три теста с подставной командой сборки прошли: успех, ошибка и явное сохранение;
bash -n и git diff --check прошли. Полная DEB-сборка в этом ходе не запускалась.

После чистки четыре службы DLP active, локальная панель HTTP200, файл PNG-опыта
на месте. Пользователь выполнил очистку системного кэша APT и предоставил
результат sudo du: осталось104КБ вместо примерно1,4ГБ. Независимый df после
очистки: на / свободно7,8ГБ (занято59%), на /home свободно13ГБ (занято34%).
Очистка завершена; установленные пакеты не удалялись.
